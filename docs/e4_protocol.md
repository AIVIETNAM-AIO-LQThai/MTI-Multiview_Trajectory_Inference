# E4 protocol: joint identification of clean persistence and channel

Drafted by Opus 5.5 on 2026-10-05, **before any E4 data**. Status: **proposed; awaiting user approval.** No code or runs exist yet.
- Branch: a new `exp/joint-identification`, from the commit that contains this file.
- Notation: [mathematical_specification.md](mathematical_specification.md), [e3_protocol.md](e3_protocol.md).
- Background and derivations: [literature_review.md](literature_review.md) §4.3.

## 1. Question, hypothesis, falsifier

**Question.** C22 showed that clean-law error is absorbed into the inferred channel. Can clean persistence η and the channel q be estimated **jointly** from unlabeled corrupted prefixes, so that absorption is removed? At what sample cost? And what remains when the clean law lies outside the assumed family?

**Derived facts the experiment takes as given.** These come from literature_review §4.3, and are re-checked by the tests in §6.
- L = 2 and L = 3: (η, q) is not identified. At L = 3 there is an exact, decision-relevant ridge: η' < η paired with a larger channel.
- L ≥ 4: separated at the pattern level for every tested truth. The minimum is L = 4.
- Against clean laws outside the first-order Markov family, the channel is not identified in general.

**Primary hypothesis H-E4** (lead and secondary physics, L = 8):
- At n = 10⁴ corrupted prefixes, on the absorption truth T0 (β = 0), the joint profile-likelihood estimator J-MLE is **equivalent** to the known-η estimator EX-MLE: the 90% CI of the replicate-paired regret difference lies within ±Δ.
- It is also **materially better** than the misspecified-η estimator ETA−-MLE (η̂ = 0.03, the C22 arm): the CI of the difference is above Δ.

**Falsifier.** H-E4 fails if, in either physics at L = 8 and n = 10⁴, J-MLE is not equivalent to EX-MLE on T0, or is not materially better than ETA−-MLE.
- If equivalence is then reached by n = 10⁵, the outcome is "**identified but costly**".
- If it is not reached by 10⁵, the outcome is "**identified in principle, not in practice**" for this n range.

## 2. Target, observation law, access, oracle

**Physics.** Lead: ρ = 0.9, c = 1, q_a = 1, q_w = 0.02, λ = 0.1. Secondary: q_w = 0.5. True η = 0.05.
- (ρ, c, q_a, q_w, λ) are supplied to every method. η is **not** supplied, except to EX-MLE and ORACLE.

**Observation law.** The S2 simulator, unchanged, plus the exogenous single-flip channel. Adaptation records are prefixes (s, ã) only: no probe, no modes, no θ.

**Target.** The aware belief μ₂ under the true law, and one-step regret 𝓔 = E_eval[κ(μ̂ − μ₂)²], where μ̂ is composed from the method's (η̂, q̂). Each regret is reported both as a fraction of VOI_clean and against the margin Δ.

**Oracle.** ORACLE uses the true (η, q). For the family-misspecification control F1, the oracle is the exact posterior over (persistence class, θ), computed by mixing flip_batch at both η values.

**Truths** (E3 ids, channel built for each L):

| id | channel |
|---|---|
| T0 | β = 0 (absorption control) |
| T3 | β = 0.2, interp α = 0.5 (all q_j > 0) |
| T4 | β = 0.35, α = 1 (concentrated) |
| T6 | β = 0.2, π_j ∝ 2^{−lag} (off the π_α family) |

**L ∈ {3, 4, 8}:**
- L = 3 is the negative control: η̂ must not concentrate on T3 (two-sided ridge), and the gap to ORACLE must not shrink.
- L = 4 is the minimal identified case.
- L = 8 is primary.

**Family-misspecification control F1** (L = 8, lead physics, truths T0 and T3):
- Each record's persistence is drawn as η_r ∈ {0.02, 0.08} with probability ½ each, so the marginal edge rate is 0.05.
- It is generated by calling the unchanged `simulate` with two Physics objects on disjoint seed streams and interleaving the records.
- **Descriptive only.** It measures what joint estimation cannot fix: spurious β̂ and harm relative to ignoring corruption. The sign is not predicted.

## 3. Stage 0: exact-law diagnostic (no estimators; must finish before stage 1)

For each (L, physics, truth), using 2 × 10⁵ records from a dedicated stream:

1. **Pattern distance.** D(η') = min over q' of TV between apparent-edge pattern laws, for η' ∈ {0.01, …, 0.12}. This is the same LP as `experiments/check_joint_identification.py`.
2. **Pseudo-true curve.** For η' on the grid:
   - q*(η') = the EM fit at η' on the large sample (population approximation);
   - KL(η') = mean log-likelihood deficit against the truth;
   - regret*(η') = the regret of composing with (η', q*(η')).
   
   This is C22 generalised: the cost of every fixed wrong η', and how detectable it is.
3. **Profile Fisher information** for η at the truth: I_prof = I_ηη − I_ηq I_qq⁻¹ I_qη.
   - Scores: analytic in q, central differences in η (h = 1e-4).
   - Predicted SE(η̂) at n = 1/√(n I_prof).
   - Predicted n for a likelihood-ratio rejection of η' = 0.03: n ≈ 1.92 / KL(0.03).

**Stage-0 stop rules:**
- At L = 3 on T3, if KL along the ridge exceeds 1e-6, or I_prof exceeds 1e-3 · I_ηη, the derivation or the code is wrong. **Stop.**
- At L = 8, if KL(0.03) < 1e-6 (record-level non-identification, contradicting the pattern-level result), **stop** and return to Opus. Do not run stage 1.
- Stage 0 also gives a prediction for stage 1. If the predicted SE(η̂) at L = 8, n = 10⁴ exceeds 0.01, H-E4 is predicted to fail at 10⁴. Record this prediction before stage 1.

## 4. Stage 1: deployable estimators and baselines

| arm | definition | role |
|---|---|---|
| ORACLE | true (η, q) | reference (regret 0) |
| EX-MLE | true η; EM over q on the full simplex (E3 MLE) | target J-MLE should match |
| **J-MLE** | profile likelihood: η-grid 0.005:0.005:0.15, then golden-section refinement to 1e-4 inside the best bracket; at each η, EM over q (E3 settings), warm-started from the neighbouring η | **primary** |
| J-MOM | nonlinear weighted least squares of pair moments m̂_ij against c²q_a² r^{\|i−j\|}(1−2(q_i+q_j)) over r ∈ (0, 1) and q in the simplex (weights from E3's MOM); η̂ = (1−r̂)/2 | cheap baseline (C24 analogue) |
| ETA−-MLE / ETA+-MLE | η̂ fixed at 0.03 / 0.08; EM over q | the C22 absorption arms to beat |
| CV-n_c | η̂ = clean-HMM MLE on a **separate clean** set of n_c ∈ {30, 100, 1,000} prefixes; then EM over q on the corrupted set | **strong practical baseline**: validate the clean law separately |
| naive | β = 0 | reference |

**Sample sizes and replicates.**
- n ∈ {300, 1,000, 3,000, 10⁴, 3 × 10⁴, 10⁵} corrupted prefixes.
- R = 20 replicates (R = 10 at n = 10⁵).
- CV arms use an independent clean set per replicate.

**Seeds** (new masters, disjoint from every master used so far: 7001, 7002, 8001, 8101, 8201, 8301, 8401):
- adaptation 8501;
- evaluation 8601: a fixed 20,000 prefixes per (L, physics, truth);
- clean validation 8701;
- stage 0 8801;
- second F1 persistence stream 8901.

## 5. Comparisons, margins, uncertainty, outcomes

**Margin.** Δ_t = clip(0.10 V₂,t, 0.002 VOI_clean, 0.02 VOI_clean), as in E3. On T0, Δ = 0.002 VOI_clean.

**Uncertainty.**
- 90% t-intervals over replicates, paired within a replicate (same adaptation and evaluation records), conditional on the evaluation set.
- Evaluation-set SE is reported separately.

**Predeclared comparisons:**
- **P1 (primary, H-E4):** J-MLE vs EX-MLE (equivalence) and J-MLE vs ETA−-MLE (superiority) on T0, at L = 8, n = 10⁴, both physics.
- **P2:** the same contrasts on T3, T4 and T6 at L = 8, and on all truths at L = 4. Report the smallest n at which J-MLE is equivalent to EX-MLE (the **crossover n**).
- **P3 (negative control):** at L = 3 on T3, the spread of η̂ does not shrink from n = 10³ to 10⁵, and the regret gap to ORACLE does not vanish.
- **P4 (practical value):** J-MLE vs CV-n_c. Find the smallest n_c at which CV is equivalent to J-MLE at n = 10⁴.
- **P5 (estimator efficiency):** J-MOM vs J-MLE regret ratio.
- **P6 (family limit, descriptive):** F1. Report β̂ for J-MLE, CV-1000 and ETA-arms, and the harm rate against naive.
- **P7 (diagnostic validity):** measured SD(η̂) vs the stage-0 predicted SE at n ≥ 10⁴. The agreement band is a ratio within [0.7, 1.4].

**Outcome interpretations (P1, both physics):**
- **Positive.** Equivalent to EX-MLE and better than ETA−-MLE at n = 10⁴.
  - C22 becomes: "η-error absorption is removable from corrupted records alone for L ≥ 4 within the Markov family, at measured cost; family error is not."
  - P4 then states whether this matters in practice: if CV-30 already matches, the practical value is limited to settings with no clean records.
- **Equivalent to ETA−-MLE** (no improvement). Joint estimation fails to use the separation at this n. Check P7: if stage 0 predicted it, the outcome is "weakly identified"; if not, the estimator is suspect (return to Opus).
- **Inconclusive** (the CI spans the margin). Report it as inconclusive. Increasing R is allowed only if declared before the run; no post-hoc additions.
- **Negative** (worse than EX-MLE beyond the margin at n = 10⁵). "Identified in principle, not in practice." C22 stands as a practical limit, and the recommended remedy is clean validation (P4).

## 7. Budget, stopping, artifacts

**Budget.**
- Stage 0: ≤ 20 min.
- Stage 1: ≤ 3 h on 18 workers.
- If the projection exceeds 4 h, reduce in this predeclared order: n = 10⁵ at L = 3 → q_w = 0.02 at L = 4 → R = 10 at n = 3 × 10⁴.

**Stop and return to Opus if:**
- any validation test fails;
- a stage-0 stop rule fires;
- the positive control fails;
- the negative control shows identification at L = 3.

No cells, truths or estimators are added after seeing results.

## 8. What the conclusion can change, and what stays unsupported

**Can change:**
- C22's wording (removable within family / costly / not removable in practice);
- the minimum-L statement (C25);
- whether "validate the clean law separately" is a necessity or merely the cheaper option (P4).

**Stays unsupported whatever the outcome:**
- validating the clean **family** from corrupted records alone (F1 only measures the damage);
- unknown physics;
- other corruption channels;
- per-record MTM detection (literature_review §4.1–4.2);
- learned neural clean models;
- real data;
- policy or closed-loop relevance.
